# SoilSight
SoilSight is an interactive web dashboard designed for visualizing and analyzing microplastic contamination data in soil samples. It provides a user-friendly interface to explore various datasets, including microplastic counts, types, and distributions across different locations in Tayabas, Quezon.

## Features
- Interactive Mapping – Explore sampling locations with contamination levels visualized on a Leaflet-powered map.
- Smart Data Filtering – Filter results by microplastic type, count, and location for deeper analysis.
- Dynamic Charts – View contamination trends and distributions through interactive ApexCharts.
- Responsive Dashboard – Accessible and optimized for desktop, tablet, and mobile.
- Intuitive Interface – Clean, modern design built with Vuetify for a consistent user experience.
- Customizable & Open Source – Easily extend or adapt SoilSight for new datasets and research needs.

## Technologies Used
- Frontend: Vue 3, Vite, Vuetify, Leaflet.js, ApexCharts, Pinia, Vue Router
- Backend: Directus (headless CMS & database)
